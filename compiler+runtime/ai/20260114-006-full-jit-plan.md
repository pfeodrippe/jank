# Full JIT Compilation - No Interpreter Fallback

## Problem
Currently jank-rs has a limited JIT that only handles simple numeric operations.
Everything else falls back to the interpreter. This is unacceptable for performance.

## Solution
Extend the JIT to compile EVERYTHING using:
1. **Tagged values (NaN-boxing)** - Already implemented in tagged.rs
2. **Native function calls** - JIT calls Rust functions for ALL operations
3. **Remove eligibility checks** - Everything gets JIT compiled

## Architecture

```
Clojure Code → Parse → JIT Compile → Native Code
                         ↓
              Calls native Rust functions for:
              - Arithmetic (+, -, *, /)
              - Collections (conj, first, rest, etc.)
              - Strings (str, subs, etc.)
              - I/O (println, etc.)
              - Everything else
```

## Implementation Steps

### Step 1: Create JIT-callable Native Functions
All core functions need `extern "C"` wrappers that work with `u64` tagged values:

```rust
#[no_mangle]
pub extern "C" fn jank_add(a: u64, b: u64) -> u64 {
    // Untag, add, re-tag
}

#[no_mangle]
pub extern "C" fn jank_first(coll: u64) -> u64 {
    // Untag pointer, call first, re-tag result
}
```

### Step 2: Extend Compiler to Use Tagged Values
Change `compile_numeric_fn` to `compile_fn` that:
- Uses `u64` for all params and returns (tagged values)
- Emits calls to native functions for ALL operations
- Handles if/let/loop/fn properly

### Step 3: Remove Eligibility Checks
- Delete `is_jit_eligible()`
- All function bodies get compiled
- No fallback to interpreter

### Step 4: Eager Compilation
- Compile functions at definition time
- Cache compiled code
- First call is always fast

## Key Insight
The JIT doesn't need to understand every operation - it just needs to emit code that:
1. Passes tagged values to native Rust functions
2. Returns the result

The complexity stays in Rust, the JIT just does dispatch.
